How to create a refrigerator mapping with 9 DS18B20 probes and an Arduino Uno board?  
Add a DHT11 for environmental conditions (even if the board doesn't heat up!!!) and send all of it to Excel with PLXDAQ.  
Step 1, find the addresses of your probes.  
Step 2, solder them, add the DHT11, configure your addresses. By placing your probes in different stable environments, with a reference probe, you will be able to define your accuracy errors and uncertainties. (EKart_Etal)  
Step 3, first mappings, you collect the data to send it to EKart_Carto.  
For the 15-probe version, we let you adapt the code :-)
